## Stack
- **GORM** over MySQL (`go-sql-driver/mysql`); connection built in `pkg/db.NewMySQLRepository`,
  returning a `MySQLClientRepository{DB, TZ}` `[code: ems/pkg/db/mysql.go]`, `[code: ems/go.mod]`.
- DSN forces `parseTime=true` and `loc=Asia/Jakarta`; DataDog SQL tracing is opt-in via
  `DB_ENABLE_TRACING` `[code: ems/pkg/db/mysql.go]`.
- Pool tuning from env: `DB_CONNECTION_MAX_LIFETIME_MINUTE`, `DB_CONNECTION_MAX_IDLE_TIME_MINUTE`,
  `DB_CONNECTION_MAX_OPEN`, `DB_CONNECTION_MAX_IDLE` `[code: ems/pkg/db/mysql.go]`,
  `[code: ems/app/appconf/config.go]`.

## Read/write/archive split
`initHTTP` builds three connections; repos receive both and route by operation
`[code: ems/cmd/boot.go]`:
- **Replica** (`r.db`) — reads.
- **Master** (`r.masterDB`) — creates/updates `[code: ems/internal/education/repository/repository.go]`.
- **Archive** — cold data; selected at request time by a context flag via `pkg/dbresolver`
  (`WithArchiveDB` / `GetDB` / `GetQuery[T]`), falling back to primary when `archiveDB` is nil
  `[code: ems/pkg/dbresolver/dbresolver.go]`.

## Generated models + query DSL — gorm/gen
`internal/datasource/model` (structs) and `internal/datasource/models` (type-safe query DSL) are
generated by **gorm.io/gen** (`cmd/orm/generate.go`) and carry `DO NOT EDIT`
`[code: ems/cmd/orm/generate.go]`, `[code: ems/internal/datasource/model/tbl_user.gen.go]`. The DSL
is activated per connection with `models.Use(db)` (aliased `empQuery`/`empQueryM`/`empQueryArchive`)
`[code: ems/cmd/boot.go]`. This layer is excluded from tests (`GO-TESTING.md` §1).

## Query idioms
- Always context-scoped and tenant-filtered: `r.db.WithContext(ctx).Table("tbl_…").Where("company_id = ?", param.CompanyID)`
  `[code: ems/internal/education/repository/repository.go]`.
- Wrap raw errors: `errs.Wrap(result.Error)`; a valid empty read may return `(nil, nil)`
  `[code: ems/internal/education/repository/repository.go]`. See `GO-ERROR-HANDLING.md`.
- Company context is also propagated through `context.Context` (`db.SetCompanyContext`) so the
  encryption plugin resolves the tenant key `[code: ems/pkg/db/company_context.go]`.

## Shared-schema constraints (gaps)
- **EMS owns no DDL.** There is no `migrations/` dir; the schema is managed by talenta-core (gap
  **G-16**) — a Fabric prototype must add no columns/tables to the shared DB, keeping new state
  on-ledger or in a separate store `[code: ems/dbconfig.yml]`.
- **Encryption rollout is phased** (gap **G-21**): read/write through the app layer, never assume raw
  column population `[code: ems/pkg/db/encryption_plugins.go]`. PII crypto is in `GO-SECURITY.md`.

## Transactions & jobs
Bulk jobs track progress in `tbl_resque_status` and row errors in `tbl_resque_payload`
`[code: ems/specs/002-bulk-import-employee-go/plan.md]`. Integration tests wrap each case in a
rollback transaction (`testutil.TestSuite`, `GO-TESTING.md` §5).
